# ReCol (ReCollection)
This BallsDex extension adds a new option to /balls collection, allowing you to pick a user. Along with that, it also comes with new UI for the command which can be toggled in the admin panel. Credits to the BallsDex team for the code that i used :3

> [!NOTE]
> The original /balls collection command will not be available until you disable the package.

> [!IMPORTANT]
> It starts with the updated UI so before you freak tf out go to admin panel -> recol settings and toggle on 'Default UI'


Installation:
```toml
[[ballsdex.packages]]
location = "git+https://github.com/cewlgruyere/ReCol.git"
path = "recol"
enabled = true
```
Paste this in the `config/extra.toml` folder. If you dont have it, create it and paste this in.

This package won't be maintained as it's fully finished and was made because i really want a user parameter!
